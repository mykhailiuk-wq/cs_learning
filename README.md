# C# Practical Assignments

A collection of practical assignments and exercises completed while learning **C# and the .NET ecosystem**.

## Overview

This repository contains practical work focused on learning C# fundamentals, understanding object-oriented programming, and exploring the core features of the .NET platform.

Each assignment serves as an opportunity to practice programming concepts, improve problem-solving skills, and gain hands-on experience with C#.

## Topics Covered

- C# syntax and language fundamentals
- Variables, data types, and control flow
- Methods, arrays, and collections
- Object-oriented programming (OOP)
- Classes, structs, interfaces, and inheritance
- Exception handling
- Generics and LINQ
- Working with files and data
- .NET libraries and application development

*The list will be updated as new topics and assignments are covered.*

## Tech Stack

- **Language:** C#
- **Platform:** .NET
- **IDE:** Visual Studio / Visual Studio Code

## Goals

- Strengthen understanding of C# fundamentals.
- Apply programming concepts through practical exercises.
- Develop clean, readable, and maintainable code.
- Build a foundation for developing applications with .NET and ASP.NET Core.

## Status

**Ongoing** — new practical assignments will be added throughout the course.
